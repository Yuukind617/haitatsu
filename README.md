# はいたつごっこ(iPad版 / GitHub Pages で公開)

4歳のお子さん向けの、生協の配達ごっこアプリです。
GitHub Pages に置いて、iPad の Safari から開いて使います。
一度開けば iPad の中に保存されるので、次からは電波がなくても開けます。

## あそびかた

1. **ちゅうもん**(おうちの人)… 品物をタッチすると ✓ がつきます(もう一度タッチでやめる)。数は いつも1つです。「おまかせ」でランダムなちゅうもんも作れます。「ちゅうもんする」を押します
2. **ちゅうもんしょ** … プリンターから、レシートのような ちゅうもんしょ が出てきて、読み上げます
   - 品物の行をタッチ → その品物だけ読みます
   - 右の「よむ」 → ぜんぶ読みます
   - 右はしの ○ をタッチ → ✓ がつきます(あつめたしるし。ぜんぶつくと「あつめたよ!」が動きます)
3. 子どもが、おもちゃの品物を あつめます
4. **あつめたよ!** を押すと、トラックが しゅっぱつ → おうちに とうちゃく
5. おうちの人が、とどいた品物をたしかめて
   - **うけとりました** → 「はいたつ かんりょう しました!」
   - **まちがってます** → トラックがバックでもどり、ちゅうもんしょ の画面にもどります

- とちゅうでアプリを閉じても、ちゅうもんは残っています
- 「ちゅうもんに もどる」で、ちゅうもんを作りなおせます

## きょうの おかいどく

ちゅうもん画面になるたびに、ランダムな品物が1つ「10〜90%オフ」になり、
「きょうの おかいどくは、ころっけ! 30パーセント オフ! おかいどくだよ!」と読み上げます。

- その品物には「30%オフ」の札がつき、ちゅうもんしょにも出ます
- 上の「おかいどく」の文字をタッチすると、もう一度読みます
- 「おまかせ」では、おかいどくの品物が入りやすくなっています(10回に8回)
- アプリを開いた直後は、最初に画面をタッチしたときに読みます(iPad の決まり)
- `config.js` の `sale` で、オフの幅や「おまかせ」で入る割合を変えられます

## 品物(26しゅるい・2ページ)

- 1ページめ:にんじん・たまねぎ・ねぎ・しいたけ・きゃべつ・とまと・りんご・ばなな・たまご・ぎゅうにゅう・さかな・かんづめ・しょくぱん・ぱん・おにぎり
- 2ページめ:まきずし・ころっけ・ぽてと・ぴざ・ほっとけーき・はんばーがー・よーぐると・じゅーす・あいす・ちょこけーき・どーなつ

ページは、上の ◀ ▶ や「1」「2」のボタン、または品物の上を左右にスワイプして切りかえます。
えらんだ品物があるページには ✓ がつきます。

おうちにない品物は、`config.js` の `items` から消すと出なくなります。

## GitHub Pages に置く手順

やることリストと同じやり方で、**新しいリポジトリ**を作ります。

1. github.com の右上「＋」→「New repository」
2. Repository name に `haitatsu` と入れ、**Public** を選んで「Create repository」
3. 「uploading an existing file」を押し、このフォルダの**中身をすべて**ドラッグ →「Commit changes」
   - `voice_tools` フォルダはパソコンで使う道具なので、入れなくてもかまいません
4. 「Settings」→「Pages」→ Branch を「main」「/ (root)」にして「Save」
5. 数分後、`https://(ユーザー名).github.io/haitatsu/` で開けます

iPad では Safari でこのアドレスを開き、共有ボタン →「ホーム画面に追加」で、ホーム画面のアイコンから使ってください。
Wi-Fi につないだまま一度閉じて開き直すと、オフラインでも開けるようになります。

### やることリストと同じ GitHub に置く場合の注意

2つのアプリは同じ `github.io` に置かれます。オフライン用の保存場所がぶつからないよう、
**やることリストの `sw.js` も新しいもの(同梱)にアップロードし直してください。**
古いままだと、やることリストを更新したときに、はいたつごっこのオフライン保存が消えることがあります
(消えても、Wi-Fi につないで開き直せば元にもどります)。

## VOICEVOX の声にする

やることリストと同じ手順です。

1. VOICEVOX を起動して、`voice_tools` の `make_voices.bat` をダブルクリック
2. 声の番号を入力して Enter
3. できた `voices` フォルダを、GitHub の「Add file」→「Upload files」でフォルダごとアップロード
4. iPad で、Wi-Fi につないだままアプリを2回開き直す

時間外の画面がないので、クレジット(VOICEVOX:キャラクター名)は ちゅうもん画面の左下に出ます。

## 設定(config.js)

| 項目 | 初期値 | 説明 |
|---|---|---|
| `items` | 26しゅるい | ちゅうもん画面に出す品物と順番(1ページ15こ) |
| `random_order` | 2〜4こ | 「おまかせ」で作るちゅうもんの品物の数 |
| `sale` | 10〜90%オフ、おまかせで 80% | きょうの おかいどく |
| `voice` | オン、はやさ 0.9 | 読み上げのオン/オフ・はやさ・声の高さ |

## ファイルの中身

| ファイル | 内容 |
|---|---|
| `index.html` `style.css` `app.js` | 画面 |
| `config.js` | 設定 |
| `items.js` | 品物・トラック・おうちの絵 |
| `voice.js` | 読み上げ(VOICEVOX の声があればそれを使う) |
| `sw.js` `manifest.json` `icon.png` | オフライン用・ホーム画面用 |
| `voice_tools/` | VOICEVOX の声を作る道具(パソコンで使う) |

## 動作確認について

パソコン上の Chrome(iPad よこ向きと同じ大きさ)で、ちゅうもん → ちゅうもんしょ → 読み上げ → トラック →
まちがい → もういちど → 配達完了、開き直したときの続き、VOICEVOX の声(仮の声で確認)まで確認しています。
**iPad の実機では未確認**です。
